# Sneha Mahapatra & Sayan Chowdhury · Wedding Invitation

Single-page wedding invitation website (one `index.html`, no build step).

- `index.html` – the whole site (HTML, CSS, JavaScript inline; Google Fonts only)
- `bg.webp` – hero watercolour
- `bride.jpg`, `groom.jpg` – portrait illustrations
- `little-couple.jpg` – picture in the arch above the footer
- `photo2.jpg`–`photo4.jpg` – photo album
- `music.m4a` – background music (starts when the guest taps the seal)

Hosted with GitHub Pages from the `main` branch.
